# Using the Practice Calendar

The Calendar lets you plan out what to practice over a stretch of days — which songs, which sections of those songs, and how long to spend on each — and then walk through that plan day by day with a built-in timer.

## Opening the Calendar

From the main practice screen, click **Calendar** in the header. You'll land on two tabs: **Plan** and **Today**.

## Setting up a practice plan

A **plan** is a block of time (a start date and an end date) that you fill with practice sessions.

1. Go to the **Plan** tab.
2. Click **New Plan**.
3. Give it a name (e.g. "Recital Prep" or "August Warmups"), and pick a start date and end date.
4. Click create. Your new plan now appears in the list on the left, along with any plans you've made before.

You can have several plans, but only one can be **active** at a time — the active plan is the one that shows up in the **Today** tab. Click **Activate** next to a plan in the list to make it the current one.

## Filling in a day

1. Select a plan from the list to see it laid out as a calendar grid, covering its start-to-end date range.
2. Click on any day in the grid.
3. In the panel that opens, search for a song by name.
4. Pick which section of that song you want to practice (e.g. "Intro," "Solo," "Verse 2") and set how long you want to spend on it.
5. Click add — it now appears as a scheduled block for that day.

Repeat this for as many songs/sections as you want on that day. Each day can have multiple blocks, practiced back to back.

A few notes:
- Each song gets its own color, so at a glance you can see which songs are scheduled across the plan.
- You can reorder blocks within a day (move them up/down) or delete a block you no longer want.
- The calendar doesn't support "repeat this every week" — if you want the same routine across multiple weeks, you'll add it to each day individually, or make a fresh plan when the current one ends.

## Practicing with the Today tab

Once you have an **active** plan with blocks scheduled for the current date:

1. Switch to the **Today** tab.
2. You'll see your blocks for today, in order, with the current one highlighted — song name, section, and how long it's scheduled for.
3. Click **Start** to begin the countdown timer for that block.
4. Use **Pause** if you need to stop briefly, and **Prev**/**Next** to move between blocks manually.
5. When a block's timer runs out, it automatically advances to the next one after a short pause.

If your active plan has no blocks scheduled for today (or you don't have an active plan yet), the Today tab will tell you so and point you back to the Plan tab to set one up.

## Quick recap

- **Plan tab** — build out a schedule: create a plan, pick a date range, and fill in days with songs/sections to practice.
- **Activate** a plan to make it "live" for the Today tab.
- **Today tab** — a simple, timed walk-through of whatever you scheduled for the current day.
